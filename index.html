使用指南

如何使用这个网站

  1. 先点击左侧“新建申请 Project”，为一个目标专业建立独立申请档案。
  2. 在 Project 表单里填写申请专业、学位阶段、申请类型、学历来源、国家/地区、VPD 状态和目标学期。
  3. 如果申请多个专业，请为每个专业单独创建 Project，避免不同专业的材料要求混在一起。
  4. 在下方输入框提问，系统会结合当前 Project 信息和 TUM 官方资料摘要生成回答。
  5. 可以使用输入框上方的关键词按钮快速填入常见问题。
  6. 需要修改 Project 信息时，点击左侧 Project 卡片里的“编辑”。

这个 Demo 的 RAG 思路

  1. 资料库参考 RAGFlow 的知识库思路：系统会维护一组 TUM 官方来源页面。
  2. 提问时会先根据当前 Project 信息识别申请意图，例如 VPD、APS、语言证明或高年级入学。
  3. 系统会按 LightRAG 的轻量思路，把 Project 背景转成申请规则，例如“非德国学历 -> VPD”“中国学历 -> APS”。
  4. AI 回答不是凭空生成，而是基于检索到的 TUM 官方资料摘要、Project 信息和聊天上下文。
  5. 每次回答下方的“RAG 检索依据”会展示本次实际参考的资料片段。

How to use this website

  1. Click “New Application Project” on the left to create a separate profile for one target program.
  2. Fill in the program, degree level, application type, educational background, country/region, VPD status and target semester.
  3. Create a separate Project for each program so that document requirements and deadlines do not get mixed.
  4. Ask questions in the chat box. The assistant uses the current Project context and TUM official guidance summaries.
  5. Use the keyword buttons above the input box to insert common application questions quickly.
  6. To update Project information, click “Edit” inside the Project card on the left.

RAG design in this demo

  1. The knowledge base follows the RAGFlow idea of keeping visible official source pages.
  2. When you ask a question, the system first detects the application intent, such as VPD, APS, language proof or higher semester entry.
  3. Following a lightweight LightRAG-style approach, the Project profile is mapped to rules such as “non-German qualification -> VPD” and “China qualification -> APS”.
  4. The AI answer is grounded in retrieved TUM guidance summaries, Project context and recent chat history.
  5. The “Retrieved Contexts” section under each answer shows the sources used for that response.
